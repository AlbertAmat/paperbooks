# Ubicaciones

Las ubicaciones representan los lugares físicos donde se encuentran tus libros — una estantería, una sala, una sede o cualquier otra cosa que tenga sentido para tu colección.

## Gestionar ubicaciones

La página de **Ubicaciones** muestra todas las ubicaciones con su **descripción** y el **número total de libros** almacenados actualmente allí.

- Haz clic en **Añadir** para crear una nueva ubicación, dándole un nombre y una descripción.
- Usa ✏️ para editar una ubicación, o 🗑️ para eliminarla (con confirmación).
- Expande la fila de una ubicación para ver los **libros almacenados allí**.

## Usar ubicaciones

Una vez creada, una ubicación está disponible en cualquier lugar donde asignes un ejemplar físico a un sitio:

- Al seleccionar una ubicación mientras [añades un libro por ISBN](#adding-books).
- Al elegir una ubicación al [añadir o editar un ejemplar de stock](#book-details) en la página de un libro.

Esto facilita responder a preguntas como "¿dónde está este libro?" o "¿qué hay en la estantería B?" de un vistazo.

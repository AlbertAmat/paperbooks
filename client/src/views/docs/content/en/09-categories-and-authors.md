# Categories & authors

Categories and authors help you classify and search your catalog. Both are managed the same simple way.

## Categories

The **Categories** page lists every category you've created (for example, *Fiction*, *Science*, *History*).

- Click **Add** to create a new category.
- Use ✏️ to rename or edit it, or 🗑️ to delete it.

Once created, a category becomes available in the **Category** dropdown on every [book's detail page](#book-details), and as a filter when [searching the library](#searching-the-library).

## Authors

The **Authors** page works the same way — a simple list you can **add**, **edit**, or **delete** authors from.

You don't have to pre-create authors before using them: when editing a book, the **Authors** field lets you search existing authors as you type, and any name that doesn't exist yet is added automatically. The Authors page is mainly useful for cleaning up or correcting entries afterwards.
